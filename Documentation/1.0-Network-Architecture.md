# **1.0 IT Operations Home Lab — Network Architecture**

## **1.1 Project Overview**

This project simulates a small enterprise IT environment using virtualization. It demonstrates Windows Server administration, Active Directory Domain Services, DNS, Group Policy, domain authentication, and departmental file sharing.

## **1.4 Network Configuration**

The virtual machines communicate through the default libvirt NAT network.

Network Component:		Configuration:
Network				192.168.122.0/24
Gateway				192.168.122.1
Domain Controller		192.168.122.10
Domain				corp.test
NetBIOS Name			CORP
Client IP Assignment		DHCP
Client DNS Server		192.168.122.10

DC01 uses a static IPv4 address and provides Active Directory Domain Services and DNS.

CLIENT01 obtains its IP configuration through DHCP and uses DC01 as its preferred DNS server to locate and communicate with the domain.

## **1.6 Departmental File Sharing**

The server hosts departmental folders under C:\CompanyShares.

Department		Network Path			Mapped Drive
IT			\DC01\CompanyShares\IT		I:
HR			\DC01\CompanyShares\HR		H:
Finance			\DC01\CompanyShares\Finance	F:

Share permissions and NTFS permissions were configured to restrict departmental access.




## **1.7 Group Policy**

Three user-based Group Policy Objects were configured:

    1. GPO_IT_MapNetworkDrive
    2. GPO_HR_MapNetworkDrive
    3. GPO_Finance_MapNetworkDrive

Each GPO automatically maps the corresponding departmental shared folder when an authorized domain user signs in.




## **1.8 Verification**
The following functionality was tested successfully:

    1. Active Directory domain controller and DNS resolution.
    2. Windows 11 client domain joining.
    3. Authentication using departmental domain accounts.
    4. Automatic departmental network drive mapping.
    5. File creation in each authorized departmental folder.
    6. Denial of access to other departments' folders.
    7. Registration of CLIENT01 in Active Directory.



## **1.9 Project Scope**
This is a self-built virtual lab for learning and demonstration purposes. It uses a single physical host and a virtual NAT network rather than production enterprise hardware or infrastructure.
