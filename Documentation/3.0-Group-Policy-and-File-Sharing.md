# **3.0 IT Operations Home Lab — Group Policy and Departmental File Sharing**

## **3.1 Overview**

Group Policy and SMB file sharing were configured to provide department-specific network drive access in the simulated enterprise environment.

The implementation uses Active Directory security groups, share permissions, NTFS permissions, and user-based Group Policy Objects (GPOs).




## **3.2 Shared Folder Structure**

The following directory structure was created on DC01:

	C:\CompanyShares
	├── IT
	├── HR
	└── Finance


The parent folder was shared over the network as:

	\\DC01\CompanyShares


Departmental folders were accessible through their respective network paths.

Department:		Network Path:			Drive Letter:
IT			\DC01\CompanyShares\IT		I:
HR			\DC01\CompanyShares\HR		H:
Finance			\DC01\CompanyShares\Finance	F:



## **3.3 Share Permissions**

The SMB share permissions were configured to grant Authenticated Users the Change and Read permissions.

Full Control was not granted.

The broad Everyone permission entry was removed and replaced with Authenticated Users.



## **3.4 NTFS Permissions**

Departmental folder permissions were configured using their corresponding Active Directory security groups.

Folder:		Authorized Group:		Permission:
IT		GG_IT_Users			Modify
HR		GG_HR_Users			Modify
Finance		GG_Finance_Users		Modify


Administrators and SYSTEM retained Full Control.

Inheritance was disabled on the parent share folder and departmental folders. Broad inherited CORP\Users entries were removed to prevent unintended access.

The effective access to a network folder is determined by the combined share and NTFS permissions.



## **3.5 Group Policy Drive Mapping**

Three user-based Group Policy Objects were created and linked to their corresponding departmental Users organizational units.

GPO:				Linked OU:		Drive Mapping:
GPO_IT_MapNetworkDrive		IT\Users		I:
GPO_HR_MapNetworkDrive		HR\Users		H:
GPO_Finance_MapNetworkDrive	Finance\Users		F:


Each drive mapping used:

    * Action: Update
    * Reconnect: Enabled
    * A department-specific network path
    * A department-specific drive letter and label
