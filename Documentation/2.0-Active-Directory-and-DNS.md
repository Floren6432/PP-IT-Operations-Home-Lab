# **2.0 IT Operations Home Lab — Active Directory and DNS Administration**

## **2.1 Overview**
Active Directory Domain Services (AD DS) and DNS were configured on the Windows Server 2025 virtual machine to simulate centralized identity and network management in a small enterprise environment.



## **2.2 Domain Controller Configuration**

Setting:			Value:
Server Name			DC01
Operating System		Windows Server 2025 Standard Evaluation
Domain				corp.test
Forest				corp.test
NetBIOS Name			CORP
IPv4 Address			192.168.122.10
DNS Role			Installed
Global Catalog			Enabled

DC01 was promoted to a domain controller by creating a new forest named corp.test.

Active Directory Domain Services and DNS were installed and configured during domain controller promotion.



## **2.3 DNS Configuration and Verification**

DC01 hosts the DNS service used by the Active Directory domain.

The following DNS lookups were performed successfully:

DNS Query:				Expected Resolution:			Result:
corp.test				192.168.122.10				Passed
DC01.corp.test				192.168.122.10				Passed
_ldap._tcp.dc._msdcs.corp.test		DC01 domain controller record		Passed

Additional DNS validation was performed using:

	dcdiag /test:dns


The domain controller passed the DNS connectivity and DNS tests.

CLIENT01 was configured to use 192.168.122.10 as its preferred DNS server to resolve domain resources.



## **2.4 Organizational Unit Structure**

The following departmental structure was created in Active Directory:

	Company
		- IT
	            - Computers
	            - GG_IT_Users
	            - Users

	        - HR
	            - Computers
	            - GG_HR_Users
	            - Users

	        - Finance
	            - Computers
	            - GG_Finance_Users
	            - Users

This structure separates departmental users, computers, and security groups for easier administration.



## **2.5 User Accounts and Security Groups**

Three fictional domain accounts were created:

Gordon Freeman		gordon.freeman		HR

Departmental Global Security Groups were created:

    GG_IT_Users
    GG_HR_Users
    GG_Finance_Users

Each user was added to the corresponding departmental security group.



## **2.6 Account Administration Exercises**

The following Active Directory administration tasks were practiced:

    1. Creating domain user accounts.
    2. Creating Global Security Groups.
    3. Assigning users to departmental groups.
    4. Inspecting user account properties and group memberships.
    5. Resetting a user's password.
    6. Disabling an account temporarily.
    7. Re-enabling a disabled account.

These exercises demonstrate basic centralized user and account administration.



## **2.7 Domain Integration Verification**

The Windows 11 Pro client, CLIENT01, was successfully joined to the corp.test domain.

Verification included:

    1. Resolving the domain name through DC01.
    2. Resolving the domain controller's fully qualified domain name.
    3. Signing in using departmental domain accounts.
    4. Confirming the CLIENT01 computer account appeared in Active Directory Users and Computers.



## **2.8 Summary**

The lab successfully demonstrated centralized domain management using Active Directory Domain Services and DNS.

Domain users were authenticated through DC01, while departmental organizational units and security groups provided a structured foundation for Group Policy and file-sharing permissions.
